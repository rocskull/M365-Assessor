# Rule definitions

`entra_phase2.yaml` contains the first production check pack. Each check is paired with a real
collector dependency, deterministic evaluation, unit test, remediation guidance, evidence fields,
and versioned CIS Microsoft 365 Foundations 7.0.0 and NIST CSF 2.0 mappings.

Future service packs are added as new YAML files; Python evaluation code does not contain framework
control identifiers.
